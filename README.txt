HOW TO VIEW LOCALLY
--------------------
1. Unzip this package anywhere on your computer.
2. Double-click index.html to open it in your browser (Chrome, Edge,
   Firefox all work). No server or install needed.
3. Click through to Privacy and Terms from the footer to confirm the
   full text renders correctly.
4. Resize the browser window (or open on your phone) to check the
   mobile layout — the menu collapses into a "Menu" button under
   about 700px width.

HOW TO DEPLOY
--------------
Upload all files and folders (keeping the assets/ folder structure
intact) to the root of your web hosting via FTP, cPanel File
Manager, or your host's upload tool. index.html should sit at the
domain root so it loads as the homepage.
